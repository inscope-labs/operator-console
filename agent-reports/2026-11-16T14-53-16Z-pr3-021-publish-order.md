# PR3-021 — Complete publish (order field adoption)

**Register ID:** PR3-021  
**Branch:** `pr3/pr3-021-publish-order-field`  
**Base:** `main` @ `f76015cb9b8057ce3609e40be13628d9b18076f7`

## Summary

Unblocks publish end-to-end readiness for the order identifier required by capability minting, after contract revision 1.2 (ADR 0014 D1 / ADR 0015) made `order` required on `GET /tasks/next` items.

- `TaskSummaryDto` and domain `Task` gain `order`.
- `TaskRepositoryImpl` maps the field.
- `TaskFieldPublishOrderResolver` returns `task.order` when non-blank; DI wires it instead of the fail-closed unresolved resolver.
- Contract conformance ratchet entry `response_missing_required:tasks-next:order` removed (DTO now consumes the field).
- Unit tests for the resolver.

Existing publish use case, ViewModel, UI, journal path, and live-head checks from Stage 3.3 remain in place. This PR does not re-implement them.
